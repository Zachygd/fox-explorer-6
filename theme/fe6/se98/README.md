# SE98 icons

These icons are from **SE98** by nestoris (https://github.com/nestoris/Win98SE), licensed under the GNU GPL version 2 (see LICENSE in this folder). They are unmodified copies, renamed to the names Fox Explorer uses; `art/make_se98.py` lists which SE98 icon each one is.

The one exception is `downloading.png`, the Downloads button animation: `art/make_download_anim.py` draws its frames over SE98's download icon, so it is a modified SE98 icon and is also under the GPL-2.0.
