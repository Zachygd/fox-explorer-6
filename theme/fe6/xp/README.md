# Windows XP style icons

From the **Windows XP High Resolution Icon Pack** by marchmountain (https://github.com/marchmountain/-Windows-XP-High-Resolution-Icon-Pack), released under **CC0 1.0** (see LICENSE). They are recreations of Windows XP's icons; Windows and Windows XP are trademarks of Microsoft. Scaled down to 24x24 and 16x16 by `art/make_xp_icons.py`, which lists the icon each one comes from; `downloading.png` is drawn from the pack's globe, document and folder icons.
