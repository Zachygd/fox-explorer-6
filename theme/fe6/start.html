Welcome to Fox Explorer 6

The classic browser look, running on a modern Firefox engine. Type an address or a search into the Address bar and click Go.

  • Tabs: Ctrl+T opens a new tab, Ctrl+W closes it.
  • Favorites: Ctrl+D adds this page; the Favorites button opens the list.
  • Add-ons: Firefox extensions install from addons.mozilla.org.
  • Dark mode: View › Color Scheme, or Tools › Internet Options.
  • Settings: Tools › Internet Options opens all modern Firefox settings.
